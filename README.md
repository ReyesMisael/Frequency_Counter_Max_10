## About The Project

This project is an implementation of a pulse coincidence technique, which is part of my master’s research project. It is used to estimate an unknown frequency of a periodic signal, often a square wave. This implementation was designed on the Quartus II platform, version 22.1. A license is not required because the free version was used.

The implementation works on the MAX 10 FPGA development kit (10M50DAF484C6GES) and combines VHDL, Altera IP catalog components, and block diagram code to interconnect all modules. This project is in continuous development, and this is a beta version. The next step is to create a complete VHDL/Verilog implementation that can run on most FPGA devices with Ethernet protocol
